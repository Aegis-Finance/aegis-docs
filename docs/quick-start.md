# Quick start

## Users

1. Add **Sonic** (chainId `146`, RPC `https://rpc.soniclabs.com`).
2. Open the [app](https://app.aegisprotocol.org) and connect.
3. Bridge via **Sonic Gateway** if you are coming from Ethereum.
4. **Wallet** → shield when you want privacy.
5. Explore **Swap**, **Lending**, **Governance**, and the rest from the sidebar.

Follow [X](https://x.com/aegisecosystem) / [Telegram](https://t.me/Aegisecosystem) for TGE timing — **AGS is not live for public trading until we say so.**

## Auditors / curious nerds

1. Clone [github.com/Aegis-Finance/Aegis](https://github.com/Aegis-Finance/Aegis).
2. Read the [whitepaper](https://github.com/Aegis-Finance/Aegis/tree/master/docs/whitepaper).
3. Verify `CHECKSUMS.sha256` + signature with `RELEASE_SIGNING_KEY.pem`.
4. Match SonicScan code to the [verified contracts](./contracts) page.

## Builders

1. Skim [Integration](./build/integration) and [Partners](./build/partners).
2. Reach out on official channels for deeper kits — we do not publish every env recipe here.
3. Run RPC you trust for production traffic.

## Token sale (when live)

Primary issuance: [tge.aegisprotocol.org](https://tge.aegisprotocol.org) — Dutch auction on Sonic. Only the auction address we announce at window open.
