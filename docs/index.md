# Introduction

Aegis is a **selective-privacy** financial protocol on [Sonic](https://docs.soniclabs.com/) mainnet (chainId **146**). Your wallet talks to Sonic RPC. This site explains the public product — what you can use, how privacy works, and how to verify you are not talking to a clone.

Sonic: sub-second finality, full EVM. Aegis: **Groth16 shielded balances** plus a modular DeFi stack — swap, lend, insure, govern, raise capital — without publishing every transfer on a permanent scoreboard.

## In one breath

- **Shielded ledger** — hold and move value in commitments; unshield when you need transparent rails.
- **Full stack** — trade, credit, stake, insure, govern, raise — one privacy grammar.
- **Honest modes** — when a pool is public, we say so.
- **On-chain governance** — timelocked votes, not a hidden admin key.
