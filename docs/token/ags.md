# AGS overview

**AGS** is the native governance and utility token of Aegis on Sonic.

## Parameters

| Field | Value |
|-------|--------|
| Max supply | 21,000,000 AGS (fixed at genesis) |
| Decimals | 18 |
| Network | Sonic mainnet (146) |

See [Tokenomics](./tokenomics) for the mainnet allocation by contract.

## Utility

- Governance voting and parameter control
- Staking and protocol security
- Liquidity mining and treasury instruments
- Fee and incentive alignment across modules
