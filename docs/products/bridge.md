# Sonic Gateway

Bridge assets from **Ethereum** to **Sonic** using the official Sonic Gateway — then use Aegis modules on chainId 146.

## Flow

1. Connect wallet on the bridge page.
2. Select asset and amount on Ethereum.
3. Complete gateway deposit per Sonic’s UI.
4. Claim or wait for finality on Sonic per gateway rules.
5. Shield or trade inside Aegis.

## Security

Use only gateway addresses from [Sonic documentation](https://docs.soniclabs.com/). Phishing sites mimic bridge UIs — bookmark official URLs.
