# Shielded+

Advanced privacy-native modules in one surface — beyond core wallet and DeFi.

## Modules

| Tab | Purpose |
|-----|---------|
| **Stealth receive** | Pay links without reusable deposit addresses |
| **Anonymous payroll** | Batch payouts privately |
| **Privacy savings** | Save inside commitments |
| **Yield vault** | Earn on shielded principal |
| **Incentives** | Claim shielded rewards |
| **Prediction** | Private prediction markets |
| **Stable vault** | Stablecoin-denominated shielded savings |
| **Credit** | Private credit profiles |
| **Bonds** | Private bond market |
| **Disclosure** | Selective proofs for auditors |
| **Relayer market** | Competing relayers for gas abstraction |

Tabs roll out in stages — the app labels each one as **Live**, **Building**, or **Roadmap**.
