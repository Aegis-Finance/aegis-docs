# Roadmap overview

Aegis ships in **phases** — Sonic DeFi first, then deeper markets, agents, and commerce surfaces. Dates are targets, not guarantees. We keep some of the longer-horizon work off this site on purpose.

## Near term

| Track | Focus |
|-------|--------|
| **Protocol** | Core modules live on Sonic; signed public releases |
| **TGE** | Dutch auction window; anti-scam communications |
| **Trading** | AGS/S live; more pairs, routing, and limit/RFQ app flows |
| **Agents** | Experimental wallet-bearing agents and micropayments |
| **Commerce** | ZK merchant paygate beta |

## Documentation map

- [2026–2030 phases](./phases) — near-term protocol, agents, commerce (high level)
- [Trading & DEX](./trading) — swap stack: live, in progress, next
- [Commerce & partners](./ecosystem) — paygate, relayers, partner onboarding

We expand when **security and product quality** are green — and we stay open to the right opportunities on this path. Follow [Community](../resources/community) for surprises.
